# Security Policy

BETHAK is a static front-end experience with no backend, no database and no credentials. Even so,
please handle any security concern responsibly.

## Reporting a vulnerability

- **Do not** open a public GitHub issue, discussion or pull request for a security problem.
- **Do not** include credentials, tokens, API keys or personal data in any issue, screenshot or log.
- Report privately instead.

> **Maintainer action required before publication:** configure a private reporting channel.
> Enable GitHub **Private vulnerability reporting** (Settings → Security → Advisories), or add a
> dedicated security contact address here. No security contact is configured yet, so this section
> must be completed by the repository maintainer.

## Scope

In scope: this repository's source code, build and deployment workflow.

Out of scope: third-party services used at runtime (YouTube IFrame Player API, hosting providers).
Please report issues in those services to their respective vendors.

## Response

Once a private channel is configured, reports will be acknowledged and triaged by the maintainer.
Please allow reasonable time for a fix before any public disclosure.
